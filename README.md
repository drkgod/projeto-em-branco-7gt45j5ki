# Catálogo de Casos · Adapta

Aplicação para apresentar e navegar casos de uso, com uma home editorial, área de casos e fluxo de entrada.

## O que existe no projeto

- página inicial de apresentação;
- catálogo detalhado de casos;
- autenticação/entrada;
- interface responsiva;
- componentes e design system compartilhados.

## Stack

`React 19` · `TypeScript` · `Vite` · `Tailwind CSS` · `shadcn/ui` · `PocketBase`

## Executar localmente

```bash
pnpm install
pnpm dev
```

## Estrutura

```text
src/pages/Index.tsx    apresentação
src/pages/Casos.tsx    catálogo
src/pages/Entrar.tsx   entrada
src/components/        componentes
```
